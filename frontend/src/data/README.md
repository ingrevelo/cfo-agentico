# Datos de la demo

`sofia-demo.json` es una **copia de `data/sofia-demo.json`** de la raíz del repositorio.

Son **datos sintéticos**: no corresponden a ninguna persona real. Están acá solo para que
las pantallas funcionen mientras la API no existe. Cuando el backend esté listo,
`src/api/cliente.ts` pasa a usar `fetch('/api/...')` y este archivo se puede borrar.

Si cambian los datos en la raíz, hay que copiarlos de nuevo acá.
