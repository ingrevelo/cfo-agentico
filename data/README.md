# data

`sofia-demo.json`: datos sintéticos de la persona de la demo (saldos, reglas, vencimientos y niveles de autonomía). Es el seed del `MockBeloAdapter` y de SQLite. Ningún dato corresponde a una persona real.

`historial-sofia.json`: 43 movimientos sintéticos de junio a noviembre de 2026 para la demo del perfilado. Contiene cuatro patrones (ingreso del cliente, alquiler, monotributo y retiro al banco), gastos de tarjeta que no forman patrón y un movimiento con un intento de prompt injection para el caso T08.
